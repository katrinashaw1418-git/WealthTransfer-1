What needs to be fixed in the wealth planner layer
Critical gaps — missing tables and fields
1. wealthPlanVersions — you need immutable versioning The current spec says "keep immutable snapshots" but doesn't define how. You need a version table that locks a plan at a point in time. Without it, any edit to a wealthPlan silently overwrites the historical record.

Add:

ts
export const wealthPlanVersions = pgTable("wealth_plan_versions", {
  id: serial("id").primaryKey(),
  wealthPlanId: integer("wealth_plan_id").references(() => wealthPlans.id).notNull(),
  versionNumber: integer("version_number").notNull(),
  snapshotData: jsonb("snapshot_data").notNull(),
  // Full plan state at this point in time
  createdBy: integer("created_by").references(() => users.id),
  createdAt: timestamp("created_at").defaultNow(),
  changeReason: text("change_reason"),
});
2. riskProfileSnapshots needs to be its own table, not just a column A risk profile stored as a column on wealthPlans will get mutated when the plan is updated. It needs to be a separate append-only table:

ts
export const riskProfileSnapshots = pgTable("risk_profile_snapshots", {
  id: serial("id").primaryKey(),
  clientUserId: integer("client_user_id").references(() => users.id).notNull(),
  wealthPlanId: integer("wealth_plan_id").references(() => wealthPlans.id),
  riskTolerance: text("risk_tolerance").notNull(), // conservative | balanced | growth | aggressive
  timeHorizonYears: integer("time_horizon_years").notNull(),
  liquidityNeedsText: text("liquidity_needs_text"),
  sourceOfWealth: text("source_of_wealth"),
  capturedBy: integer("captured_by").references(() => users.id),
  capturedAt: timestamp("captured_at").defaultNow(),
});
3. clientObjectives is named but not defined The spec mentions it but gives no schema. At minimum you need:

ts
export const clientObjectives = pgTable("client_objectives", {
  id: serial("id").primaryKey(),

  targetDate: date("target_date"),
  priority: text("priority").notNull().default("primary"), // primary | secondary

});

Add:

ts
export const adviceDisclaimerAcknowledgements = pgTable("advice_disclaimer_acknowledgements", {

Logic gaps — rules not defined
