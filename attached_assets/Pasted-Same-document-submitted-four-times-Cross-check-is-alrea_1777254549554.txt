**Audit log standardisation** — the `writeAuditLog({ before, after })` shared helper. This must land before any of the remaining sprint tasks (planner UI, document storage, SOA hook) because those tasks add new write paths, and those write paths must use the standard from day one.

Create `server/services/auditLogService.ts`:

```ts
import { db } from "../db";
import { auditLogs } from "../../shared/schema";

type AuditLogParams = {
  userId: number;
  action: string;
  resourceType: string;
  resourceId: string | number;
  before: Record<string, unknown> | null;
  after: Record<string, unknown> | null;
  ipAddress?: string;
  metadata?: Record<string, unknown>;
};

// All advice and money writes must call this function.
// Never construct audit log metadata inline at call sites.
// This is the single standard — before + after state is required on every write.
export async function writeAuditLog(
  params: AuditLogParams,
  tx?: typeof db
): Promise<void> {
  const client = tx ?? db;

  await (client as typeof db).insert(auditLogs).values({
    userId: params.userId,
    action: params.action,
    resourceType: params.resourceType,
    resourceId: String(params.resourceId),
    metadata: {
      before: params.before,
      after: params.after,
      ipAddress: params.ipAddress ?? null,
      ...params.metadata,
    },
  });
}
```

Then retrofit every existing advice and money write to use it. The pattern at every call site is:

```ts
// Before the write — capture current state
const before = await db.query.adviceRecords.findFirst({
  where: eq(adviceRecords.id, id)
});

// Perform the write
await db.update(adviceRecords).set(changes).where(eq(adviceRecords.id, id));

// After the write — capture new state
const after = await db.query.adviceRecords.findFirst({
  where: eq(adviceRecords.id, id)
});

// Write audit log with before + after
await writeAuditLog({

```

For money writes, the same pattern applies — capture wallet/ledger state before and after every transaction, fee deduction, or reversal and write it through the helper.
