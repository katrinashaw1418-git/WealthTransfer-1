Session 23 — 10C Fee Engine

Purpose:

Calculate, approve, journal and reconcile adviser/platform fees from active DBFO-compliant fee consents.

This is the first real-money-adjacent layer, so build it in two gates:

Gate A: calculate + journal only
Gate B: wallet deduction only after admin approval

Do not start with automatic deductions.

ASIC says ongoing fee consent ceases 150 days after the reference day unless renewed, and if consent ceases the provider must not continue arranging deductions without new written consent. Netwealth’s own ongoing advice fee consent forms use the same renewal window: 60 days before to 150 days after the reference date.

2. Fee calculation logic

Create:

server/services/fee-engine.ts

Core rule:

Fee can accrue only if:
- feeConsent.renewalStatus = active
- feeConsent.withdrawnAt is null
- today <= feeConsent.consentExpiryDate
- adviserFeeRule.status = active
- adviser is linked to client
function calculateDailyFee({
  baseAmount,
  rateBps,
}: {
  baseAmount: number;
  rateBps: number;
}) {
  return (baseAmount * (rateBps / 10000)) / 365;
}

Split:

function splitFee(gross: number, adviserSplitBps: number, platformSplitBps: number) {
  const adviserAmount = gross * adviserSplitBps / 10000;
  const platformAmount = gross * platformSplitBps / 10000;

  return {
    adviserAmount,
    platformAmount,
  };
}

For base amount:

Use portfolio/wallet-derived AUM snapshot only.
Do not use fake performance.
If no AUM available, baseAmount = 0 and fee = 0.
