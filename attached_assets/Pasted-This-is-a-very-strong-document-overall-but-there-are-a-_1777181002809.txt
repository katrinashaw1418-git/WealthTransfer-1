## ✅ Fix (must implement later)

Never trust stored flags:

```ts
function canExecute(adviceRecordId) {
  const advice = getAdviceRecord(adviceRecordId);
  const feeConsent = getActiveFeeConsent(adviceRecordId);

  return (
    advice.soaIssued &&
    (advice.soaViewed || advice.soaDownloaded) &&
    advice.adviceAccepted &&
    feeConsent?.status === "active" &&
    feeConsent.consentExpiryDate > now()
  );
}
```
