Core permission rule

Every adviser client API must run:

await adviserCanAccessClient(adviserUserId, clientUserId)

If false:

return res.status(403).json({ error: "Client not linked to adviser" });

End-to-end business flow
1. Adviser logs in
2. System detects role = adviser
3. Redirect to /adviser/dashboard
4. Adviser views linked clients only
5. Adviser opens client detail
6. Adviser reviews portfolio and products
7. Adviser creates investment instruction
8. Client receives pending instruction
9. Client approves/rejects
10. If approved, system processes
11. Fee consent checked before deduction
12. Reports generated from real data only
