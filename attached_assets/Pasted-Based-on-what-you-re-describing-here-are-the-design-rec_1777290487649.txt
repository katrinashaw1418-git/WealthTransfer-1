What is working well — keep these:

Tab structure (Overview, Transactions, Advice & Fees, Wealth Planner) is correct and follows the role separation built into the system

Total value prominently displayed

What needs improvement:
1. The wallet display is too raw
Listing currencies as a plain text dump (CAD: 150,000, GBP: 75,000, BTC: 0.5) looks like a debug output. Replace with a card or table that shows currency, balance, and AUD equivalent side by side so the adviser can see the full picture at a glance.
2. "Portfolio (read-only)" label needs context
The adviser needs to know why it is read-only and what they can do instead. Add a small note: "Portfolio data is sourced from the custodian. To make changes, use the Advice and Fees tab to initiate a recommendation."
3. Multi-currency total value needs a note
$4,849,850.70 — what FX rate was used to calculate this? Add a small label: "Total value in AUD as at [date] using [rate source]." Without this, the number is not auditable.
4. Missing allocation breakdown
The overview should show a simple asset class or currency breakdown — fiat vs crypto vs stablecoin — so the adviser can see concentration risk immediately without clicking into holdings.
5. View Holdings link placement
It is currently in the header area. Move it to be a button within the Overview tab, contextually near the portfolio total. Links in headers get missed.
6. Professional investor flag
"Professional" is displayed but there is no visual distinction from a retail client layout. Professional investors have different disclosure requirements. Consider a subtle but clear banner: "This client is classified as a wholesale/professional investor. Standard retail disclosure rules may not apply."
7. Wealth Planner tab
Based on the build, the planner tab should show the client's objectives, active advice record status, and any pending disclaimer acknowledgements. If the client has not yet acknowledged the disclaimer, the tab should show the gate message rather than an empty state.
8. No action buttons visible
The adviser is in read-only portfolio view but there is no clear path to the next action. Add a persistent action bar or sidebar with: "Create advice record", "Upload document", "Add note" — all scoped to what the adviser can actually do from this page.
